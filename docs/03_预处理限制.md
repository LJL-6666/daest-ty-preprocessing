# 预处理限制

## TY 数据集

### 1. 滤波频带 0.05–47 Hz 的依据

- 下限 0.05 Hz：保留慢波成分（与 FACED 一致）
- 上限 47 Hz：避开 50 Hz 工频干扰
- 与建模仓库的 `FACED_05_47` 配置同名，口径一致

### 2. ICA 未做

`Preprocessing_tongyong.py` 中有 `eeg_ica()` 方法，但 `main_tongyong.py` 默认未调用。
眼电/肌电伪迹依靠坏道插值和后续建模中的稳健归一化抑制。

### 3. 单位差异

第一批被试（001–047）单位为 μV，第二批（048+）为 V。
`unit_check()` 自动检测并统一转换为 μV。

### 4. 坏道插值阈值

- 阈值 1：幅值超过 ±100 μV
- 阈值 2：局部方差超过邻居 3 倍
- 比例阈值：超过 30% 时间点异常则判定为坏道

### 5. 播放顺序

被试实际观看顺序随机打乱，数据存盘按素材编号 1–28。
真实播放顺序从问卷 CSV 读取（`read_video_order_from_csv`）。
**若问卷缺失，代码静默跳过播放序重排（仅 WARNING），导致口径变化。**

### 6. 讲述任务触发码

讲述任务使用触发码 22 标记视频开始，与观影任务不同。
`_count_22_in_folder()` 用于检测讲述数据完整性。

## FACED 数据集

### 1. 纯 Python/MNE，不依赖 MATLAB

主线由 `src/main_faced.py` + `src/Preprocessing.py` 读 `.bdf` 完成，无外部工具依赖。
`legacy/` 下基于 EEGLAB `.set` 的旁支需要 MATLAB，但**未用于任何已发表结果**
（其输入 `.set` 产出于 2025-11，晚于主线 pkl 的 2025-09 两个月）。见 `docs/04_版本溯源.md`。

### 2. 播放顺序来源

从 `After_remarks.mat` 的 `vid` 字段读取，与 TY 的问卷 CSV 机制不同。

### 3. 拼接逻辑

`Preprocessing.data_concat()` 在内存中按播放顺序依次追加 28 个 30 s 片段，
逐被试存为一个 pkl，再由 `convert_pkl_to_mat.py` 转置为 `(channel, vid*time)` 存 `.mat`。

### 4. ICA 无固定随机种子

`eeg_ica()` 使用 `method='fastica'`、`max_iter='auto'`，未设 `random_state`。
重跑得到的成分次序可能不同，因此本仓库归档的是**产出已用数据的那一版代码**，
数据本身请以 `MANIFEST/` 记录的产物为准，而非重新预处理。
