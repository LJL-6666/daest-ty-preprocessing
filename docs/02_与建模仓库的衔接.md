# 与建模仓库的衔接

本仓库产出 TY pkl 和 FACED .mat，供 [`daest-ty-mainline`](https://github.com/LJL-6666/daest-ty-mainline) 使用。

## 环境变量

建模仓库通过以下环境变量引用本仓库产出：

```bash
export DAEST_PREP_ROOT=/path/to/daest-ty-preprocessing   # 本仓库根目录
export DAEST_DATA_ROOT=/path/to/TY/data                   # 原始数据根目录
```

建模仓库的 `src/cfgs/data/*.yaml` 中：

```yaml
data_dir: '${oc.env:DAEST_PREP_ROOT}/output/9_movie'
pkl_file: 'data_9class_movie.pkl'
```

## 数据流

### TY 数据集

```
原始脑电 46 GB (.bdf)
    ↓ 本仓库 main_tongyong.py（0.05–47 Hz 滤波）
逐被试 pkl：output/movie/*.pkl, output/communication/*.pkl
    ↓ 本仓库 extract_9class_*.py
9 类 pkl：data_9class_movie.pkl (52人), data_9class_communication.pkl (118人)
    ↓ 本仓库 extract_8class_*.py（+ 问卷 CSV）
8 类自评 pkl：data_8class_movie_self.pkl, data_8class_communication_self.pkl
    ↓ 建模仓库侧筛 matched51
matched51 pkl：data_9class_movie_matched51.pkl (51人), data_9class_communication_matched51.pkl (51人)
    ↓ 建模仓库 train_ext → extract_fea → train_mlp
16 个实验结果
```

### FACED 数据集

```
FACED 原始 .bdf（Data/subXXX/）+ After_remarks.mat（播放顺序）
    ↓ 本仓库 main_faced.py + Preprocessing.py（MNE）
0.05–47 Hz/Processed_data/subXXX.pkl        (123 人)
    ↓ 本仓库 convert_pkl_to_mat.py（pkl → .mat）
0.05–47 Hz_mat/processed_data/*.mat
    ↓ 建模仓库 FACED_05_47 配置
建模仓库 train_ext → extract_fea → train_mlp
```

## 若 pkl / mat 不在本地

按 `MANIFEST/artifacts.tsv` 中的命令重跑，或从归档拷贝。
