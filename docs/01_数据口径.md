# 数据口径

本仓库产出 TY 4 种 pkl 和 FACED .mat，供 `daest-ty-mainline` 建模仓库使用。

## TY 数据集

### 公共参数

| 参数 | 值 |
|---|---|
| 采样率 | 250 Hz（降采样后） |
| 通道数 | 31 |
| 每视频点数 | 7500（30 秒 × 250 Hz） |
| 视频数 | 28 |
| 滤波频带 | **0.05–47 Hz** |
| 参考 | 平均参考 |
| 坏道处理 | 插值（阈值见 `Preprocessing_tongyong.py`） |

### 4 种 pkl

| pkl | 被试数 | 标签体系 | 来源脚本 |
|---|---|---|---|

| `data_9class_communication.pkl` | 118 | 素材 9 类 | `extract_9class_communication.py` |
| `data_8class_movie_self.pkl` | 52 | 自评 8 类（argmax，无中性） | `extract_8class_movie_self.py` |

### 8 类标签（自评）

8 维情绪评分取 argmax：**anger, disgust, fear, sadness, amusement, inspiration, joy, tenderness**（无中性）。

无效规则：全 0 / 全 NaN / 缺评 → 标签 = -1，按视频剔除。

### 无效标签比例

| 任务 | 总单元格 | 有效 | 无效 | 比例 |

| 观影自评 | 52 × 28 = 1456 | 1403 | 53 | 3.64% |
| 讲述自评 | 118 × 28 = 3304 | 3189 | 115 | 3.48% |

讲述侧两人（066、067）整份问卷缺评，故讲述自评实际 n = 116。

## FACED 数据集

### 公共参数

| 参数 | 值 |
|---|---|
| 采样率 | 250 Hz |
| 通道数 | 32 |
| 每视频点数 | 7500（30 秒 × 250 Hz） |
| 视频数 | 28 |
| 滤波频带 | **0.05–47 Hz** |
| 来源 | 原始 `.bdf`（`Data/subXXX/{data.bdf, evt.bdf}`） |
| 被试数 | 123 |

### 处理流程

```
FACED 原始 .bdf（Data/subXXX/{data.bdf, evt.bdf}）+ After_remarks.mat
    ↓ main_faced.py + Preprocessing.py（MNE）
      重采样 250 Hz → 0.05–47 Hz 带通 → 坏道插值(thresh1=3, proportion=0.3)
      → ICA(fastica) → 平均参考 → data_concat 按播放顺序拼接
0.05–47 Hz/Processed_data/subXXX.pkl        (123 人)
    ↓ convert_pkl_to_mat.py（pkl → .mat，转置为 (channel, vid*time)）
0.05–47 Hz_mat/processed_data/*.mat
    ↓ 建模仓库 FACED_05_47 配置
```

### 输出

| 输出 | 说明 |
|---|---|
| `0.05–47 Hz_mat/processed_data/*.mat` | 每被试一个 .mat，含 `data_all_cleaned` 和 `n_samples_one` |
