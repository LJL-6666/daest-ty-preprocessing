# 版本溯源：哪一份代码产出了哪一份数据

本仓库归档的是**主线正确版**。历史上同一批脚本存在多个副本与分支，本文用文件
md5、mtime 与数据产出时间三重证据固定对应关系，避免后续混淆。

## 1. FACED 链路

### 主线（本仓库归档的版本）

```
Data/subXXX/{data.bdf, evt.bdf, After_remarks.mat}
  + 一些背景/Recording_info.csv
  ↓  src/main_faced.py + src/Preprocessing.py     （MNE，不需要 MATLAB）
     down_sample(250) → band_pass_filter(0.05, 47)
     → bad_channels_interpolate(thresh1=3, proportion=0.3) → eeg_ica()
     → average_ref() → data_concat（按 After_remarks 的播放顺序拼接）
  ↓
0.05–47 Hz/Processed_data/subXXX.pkl          （2025-09-15 18:29，123 人）
  ↓  src/convert_pkl_to_mat.py
0.05–47 Hz_mat/processed_data/subXXX.mat      （2026-02-06 17:35，DAEST train_ext 的输入）
```

`--clisa-or-not yes` 时额外产出 `4–47 Hz/Clisa_data/`（在 0.05–47 基础上再 4–47 Hz 带通）。
